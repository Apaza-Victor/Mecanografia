La tecla Shift

Shift (mayús) se usa para mayúsculas y símbolos. La regla de oro: usa el Shift de la mano opuesta.

Letra con mano izquierda

Shift der + Z = ZShift der + C = CShift der + A = A

Letra con mano derecha

Shift izq + M = MShift izq + N = NShift izq + J = J
¿Por qué? Si usaras el Shift de la misma mano, tendrías que detener la escritura para mover el meñique. Con el Shift cruzado, una mano prepara mientras la otra escribe.

Números y símbolos

Cada tecla numérica tiene dos caracteres:

`º1!2"3·4$5%6&7/8(9)0='?¿¡←

Sin Shift → número. Con Shift → símbolo de arriba.

Shift+1 = ! · Shift+2 = " · Shift+3 = ·Shift+4 = $ · Shift+5 = % · Shift+7 = /
